# Demo 3 — иммутабельные обновления

## Что изменено

Логика bookmark toggle вынесена в чистую функцию `toggleBookmarkId`. Она не изменяет существующий
массив и в обоих случаях возвращает новый:

```ts
const nextIds = currentIds.includes(evidenceId)
  ? currentIds.filter((id) => id !== evidenceId)
  : [...currentIds, evidenceId];
```

- `filter` создаёт новый массив без выбранного ID;
- spread создаёт новый массив и добавляет ID;
- `push`, `splice` и присваивание по индексу не используются;
- функциональный setter получает предыдущее значение и возвращает новое.

Объекты заметок и Hypothesis draft также обновляются через object spread, поэтому предыдущий объект
state не изменяется.

## Почему прямая мутация иногда выглядит рабочей

React сравнивает предыдущее и следующее значение state через `Object.is`. Если изменить существующий
массив через `push` и передать setter-у ту же ссылку, React может решить, что значение не изменилось,
и пропустить render.

Иногда мутация всё же появляется на экране, потому что другой state или родительский компонент
случайно вызвал render. Это не делает мутацию безопасной: старое и новое состояние уже ссылаются на
один изменённый объект, поэтому другие компоненты могут получить неожиданные данные.

## Связь с ошибкой сортировки в vanilla-приложении

В vanilla-версии `filteredEvidence` иногда ссылался на тот же массив, что и master list. Вызов
`.sort()` изменял этот общий массив на месте, поэтому исходный порядок терялся.

Безопасный вариант сначала создаёт отдельный массив:

```ts
const sortedEvidence = [...filteredEvidence].sort(compareEvidence);
```

Bookmark toggle использует то же правило: старое значение остаётся неизменным, а React получает
новую ссылку. Поэтому один state update не может незаметно переписать предыдущий снимок массива.

## Как показать Demo

1. Поставить breakpoint перед `return nextIds` в `src/react/state/bookmarks.ts`.
2. Нажать bookmark в Evidence.
3. Проверить `currentIds`, `nextIds` и выражение `Object.is(currentIds, nextIds)` — результат должен
   быть `false`.
4. Убедиться, что содержимое `currentIds` не изменилось.
5. Повторить для добавления и удаления bookmark.
